# Vision

rePugnant (`rpg`) lets developers write useful documentation while they are already reading and editing code. Its annotations feel like comments, are fast in terminal editors, and become navigable Markdown and web documentation without requiring a separate documentation-writing workflow.

The tool serves teams that want code-adjacent explanations, code quotes, searchable knowledge, and revision history. It must keep stable links over time, make documentation drift visible before commits, and remain practical for small trusted-network deployments.
