# Web style

Use React, TypeScript, and Tailwind. The interface is a documentation workspace, not a marketing site: information-dense, calm, modern, and responsive. Avoid card-heavy layouts and oversized “hero” headings. Use normal readable heading sizes, generous but not wasteful spacing, restrained neutral surfaces, and one subtle accent color.

Desktop layout may use a navigation tree, central document pane, and contextual revision/details sidebar. On mobile, these become accessible drawers or stacked views without hiding core reading, search, or navigation features. Maintain semantic HTML, keyboard navigation, visible focus states, sufficient contrast, and responsive testing in Chromium.

Use the same visual treatment for the same action everywhere. Buttons perform actions; links navigate. Tables must remain readable on narrow screens. Do not use color as the only status indicator.
